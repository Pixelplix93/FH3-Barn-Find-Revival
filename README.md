## How to use

1. Download the **[UWP or Azimuth version](../../releases)** and extract the ZIP.
2. Download **[Forza Crypto Tool](https://github.com/DVS-code/Forza-Crypto-Tool/releases)** separately. Place `ForzaCryptoTool.exe` next to Barn Find Revival, or select it using **Browse**.
3. **Close Forza Horizon 3** and launch Barn Find Revival.
4. Select your **Save Folder**:
   - **UWP:** Your `wgs` folder or local `User_...` save folder.
   - **Azimuth:** Your Azimuth installation folder.
5. Select the barn finds you want and click **Activate**.

**That's it!** Your save is backed up automatically.

## When do the map markers appear?

You can activate both barn finds **after receiving your first car**, even before Warren's first barn-find call. The purple search areas appear **after Warren announces the first regular barn find**.
